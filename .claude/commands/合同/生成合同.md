Run the contract generation script with the date provided by the user.

Steps:
1. Extract the date from the user's message (format: YYYY-MM-DD)
2. Run: `python3 /Users/shawlee/Greax/generate_contract.py <date>`
3. Report: generated files, factory names, SKU count, quantities, totals
4. Clearly note any skipped SKUs (not found in price list)

## Larzonic 与普通订单分开生成

订货计划共享表的 **Larzonic sheet** 会和其他 sheet（脏衣篮订货、铁网鞋架、铁线）**分别生成独立合同**，即使是同一家工厂也不例外。

| 来源 | 价格列 | 合同表头 |
|---|---|---|
| 普通 sheet（脏衣篮订货 / 铁网鞋架 / 铁线） | 含税价 | 价格列显示「含税价」 |
| Larzonic sheet | 出厂价 | 价格列显示「出厂价」 |

同一工厂同一日期最多会生成 2 份合同，编号连续递增，互不干扰。

## 日常操作

在订货计划表填好数量后，说"帮我生成 YYYY-MM-DD 的合同"即可。
合同文件自动保存到各工厂对应文件夹，打印盖章即可。

## 新增工厂

编辑 `/Users/shawlee/Greax/config.json`，在 `factories` 里新增：

```json
"工厂全名（与订货计划表完全一致）": {
  "contract_prefix": "合同编号前缀，如 01XXXX",
  "base_folder": "/合同存放根目录",
  "file_prefix": "文件名前缀，如 XXX合同",
  "seller_name": "工厂全名",
  "seller_contact": "联系人",
  "seller_phone": "电话",
  "bank_name": "开户行",
  "bank_account": "账号",
  "bank_holder": "户名",
  "payment_terms": "付款条件",
  "buyer_contact": "我方联系人",
  "buyer_phone": "我方电话",
  "price_col": "含税价"
}
```

- `base_folder` 填根目录，年份子文件夹自动创建
- 新工厂文件夹内需放一份已有合同作为模板

## 新增 SKU

打开 `/Users/shawlee/Desktop/产品价格表.xlsx`，新增一行：

| A: SKU | B: 工厂全名 | C: 出厂价 | D: 含税价 | E: 产品名称 | F: 参数 |

- 每个颜色变体单独一行，一行一个 SKU
- 产品名称和参数会自动带入合同
- 新 SKU 图片首次留空；只要该 SKU 出现在任意一份历史合同里并带有图片，后续生成时会自动沿用

## 文件路径变更

只需修改 `config.json`，脚本无需改动：
- `order_plan_file`：订货计划表路径
- `price_list_file`：产品价格表路径
- `factories.XXX.base_folder`：某工厂合同根目录

---

## 合同样式

- 数据行样式由 `_fill_contract_sheet` 统一写入（宋体 11pt，四边细线边框，自动换行）
- 合计行以下的空行边框自动清除，不影响打印页数
- 若样式出现异常，检查 `generate_contract.py` 中的 `_COL_ALIGN` 和 `_FULL_BORDER`
