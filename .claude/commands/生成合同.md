Run the contract generation script with the date provided by the user.

The user will invoke this skill with a date, for example:
`/生成合同 2026-06-01`

Steps:
1. Extract the date argument from the user's message (format: YYYY-MM-DD)
2. Run: `python3 /Users/shawlee/Greax/generate_contract.py <date>`
3. Report the output to the user, including which contracts were generated, how many SKUs, quantities, and totals
4. If any SKUs were skipped (not found in price list), mention them clearly
5. Tell the user where the files were saved (factory folder paths)

---

## 日常下合同操作

**每次下合同只需一步：**
在订货计划表填好数量后，说"帮我生成 YYYY-MM-DD 的合同"即可。
合同文件自动保存到各工厂对应文件夹，打印盖章即可。

---

## 新增供应商（工厂）

只需编辑 `/Users/shawlee/Greax/config.json`，在 `factories` 里新增一个块：

```json
"工厂全名（与订货计划表中完全一致）": {
  "contract_prefix": "合同编号前缀，如 01XXXX",
  "base_folder": "/合同存放根目录，如 /Users/shawlee/好消息/工厂/XXX/合同",
  "file_prefix": "文件名前缀，如 XXX合同",
  "seller_name": "工厂全名",
  "seller_contact": "工厂联系人姓名",
  "seller_phone": "工厂联系人电话",
  "bank_name": "开户行",
  "bank_account": "银行账号",
  "bank_holder": "银行户名",
  "payment_terms": "付款条件，如 货款月结，次月25号",
  "buyer_contact": "我方联系人姓名",
  "buyer_phone": "我方联系人电话",
  "price_col": "含税价"
}
```

**注意事项：**
- `base_folder` 填根目录即可，年份子文件夹（如 `26年`）自动创建
- 工厂全名必须和订货计划表里填的名称一模一样（包括空格）
- 需要在新工厂的合同文件夹里放一份已有合同作为模板（脚本复制它的格式）

## 新增产品（SKU）

**第一步：在价格表添加一行**
打开 `/Users/shawlee/Desktop/产品价格表.xlsx`，新增一行：

| A: SKU | B: 工厂全名 | C: 出厂价 | D: 含税价 | E: 产品名称 | F: 参数 |
|--------|-----------|---------|---------|-----------|--------|

- 多颜色变体可合并写在 A 列，如 `N03SR018BB/BR /WW`，脚本自动展开
- E、F 列填好后合同里会自动带入，无需其他操作

**第二步：准备产品图片（可选但推荐）**
新 SKU 第一次生成合同时，C 列（图片）会留空。
下次这个 SKU 出现在任意一份合同后，脚本会自动学到它的图片，后续合同就能自动填入。

如果需要第一次就有图片，提前把图片用 SKU 命名放入图片文件夹（需在 `config.json` 配置路径后生效，功能待实现）。

## 文件移动

只需修改 `config.json` 对应字段，脚本不需要改：
- `order_plan_file`：订货计划表路径
- `price_list_file`：产品价格表路径
- `factories.XXX.base_folder`：某工厂的合同根目录

---

## 产品图片说明

- 脚本自动从历史合同提取每个 SKU 的产品图
- 所有产品图打印尺寸固定为 **30mm × 43mm**，不受原图大小影响
- 源图建议宽度 400px 以上以保证清晰度
- 新 SKU 无历史合同时图片列留空，不影响合同其他内容生成
