Run the contract generation script with the date provided by the user.

The user will invoke this skill with a date, for example:
`/生成合同 2026-06-01`

Steps:
1. Extract the date argument from the user's message (format: YYYY-MM-DD)
2. Run: `python3 /Users/shawlee/Greax/generate_contract.py <date>`
3. Report the output to the user, including which contracts were generated, how many SKUs, quantities, and totals
4. If any SKUs were skipped (not found in price list), mention them clearly
5. Tell the user where the files were saved (factory folder paths)

---

## 配置与维护说明

所有配置集中在 `/Users/shawlee/Greax/config.json`，**无需修改代码**。

### 新增工厂
在 `config.json` 的 `factories` 字段里添加一个新块：

```json
"工厂全名": {
  "contract_prefix": "合同编号前缀",
  "base_folder": "/合同存放根目录",
  "file_prefix": "合同文件名前缀",
  "seller_name": "工厂全名",
  "seller_contact": "联系人",
  "seller_phone": "电话",
  "bank_name": "开户行",
  "bank_account": "账号",
  "bank_holder": "户名",
  "payment_terms": "付款条件",
  "buyer_contact": "买方联系人",
  "buyer_phone": "买方电话",
  "price_col": "含税价"
}
```

合同存放目录会**自动创建**，无需手动建文件夹。

### 新增 SKU
在 `/Users/shawlee/Desktop/产品价格表.xlsx` 新增一行：

| A: SKU | B: 工厂 | C: 出厂价 | D: 含税价 | E: 产品名称 | F: 参数 |
|--------|--------|---------|---------|-----------|--------|

- E/F 列填好后，合同里会自动带入，无需其他操作
- 多颜色变体可合并写在同一行，如 `N03SR018BB/BR /WW`，脚本会自动展开

### 移动文件
修改 `config.json` 里对应的路径字段即可，脚本本身不需要改动：
- `order_plan_file`：订货计划表路径
- `price_list_file`：产品价格表路径
- `factories.xxx.base_folder`：各工厂合同根目录

### SKU 产品名称查找顺序
1. 历史合同（自动扫描各工厂合同目录）
2. 价格表 E 列备注
3. 订货计划表里的中文名
